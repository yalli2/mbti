# 타입 심포니 · Type Symphony

> 서로 다른 선율이 하모니가 되는 시간 — 성인 대상 HR 성격 유형(MBTI) 학습 워크숍

교재(MBTI 기초 슬라이드)의 흐름을 **9개 챕터**로 나누어, 수강생이 같은 방에 모여 **직접 실습하고 모두의 결과를 실시간으로 겹쳐 보는** 정적 웹사이트입니다. 빌드 과정 없이 GitHub Pages에서 바로 동작합니다.

**사이트:** https://yalli2.github.io/mbti/

## 챕터

| # | 제목 | 실습 | 함께 보기(도표) |
|---|------|------|----------------|
| 1 | 유형이란 무엇인가 | 오해 바로잡기 · 기대 키워드 | 정답률 막대 · 키워드 분포 · 목표 월 |
| 2 | 선호의 발견 | 서명 실험(선호/비선호 손) | 레이더 · 에너지 격차 점도표 |
| 3 | 에너지의 방향 (E/I) | 가설 → 8문항 → 명확도 | 선호 스펙트럼 · 미국/영국 성인 비교 |
| 4 | 정보를 받아들이는 방식 (S/N) | 〃 | 〃 |

| 8 | 일터에서 보는 16유형 | 유형 탐색기 · 공감 체크 | 공감 문장 순위 · 두 유형 비교 |

각 챕터는 **배우기 → 실습하기 → 함께 보기 → 확인하기(퀴즈 3문항)** 4단계입니다.

## 실시간 공유 켜기 (Firebase Realtime Database)

기본은 **단독 모드**(브라우저 저장 + 가상 참가자 12명 샘플)입니다. 실제 수강생끼리 공유하려면:

1. Firebase 콘솔에서 Realtime Database를 만들고 URL을 복사합니다.
2. `config.js`의 `firebaseUrl`에 붙여 넣습니다.
3. 규칙(Rules)에 아래를 추가합니다(`type-symphony` 경로만 공개).

```json
{ "rules": { "type-symphony": { ".read": true, ".write": true } } }
```

수업마다 `?room=HR2026` 처럼 방 코드를 붙인 링크를 나눠 주면 같은 방끼리만 결과가 섞입니다.

## 저작권 안내

- 공식 MBTI® Form M의 문항과 채점표는 **사용하지 않았습니다.** 8문항 간이 문항, 16유형 프로필 문장, 도해는 교재의 개념을 바탕으로 새로 작성했습니다.
- 성인 인구 분포 수치는 교재가 인용한 공개 통계(MBTI Manual 3판)입니다.
- 학습용 자료이며 공식 검사가 아닙니다. MBTI®는 The Myers & Briggs Foundation의 등록 상표입니다.
